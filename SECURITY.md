# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability within PURR, please report it privately.

- Do **not** open a public issue.
- Send an email to the repository maintainer via GitHub security advisories or directly to the project contact.
- Please include steps to reproduce, sample code, and potential impact.

We will acknowledge your report within 48 hours and provide a fix timeline.
