# Карточка задачи
## Задача
Справка стенда перечисляет все четырнадцать режимов, а вердикт пробы P1-9 не начинается со слова «мутирует», когда она зелёная.
## Что меняем
`tools/crash_harness.py` — docstring, который `main()` печатает как справку при запуске без аргументов. Сейчас в нём шесть режимов из четырнадцати: не упомянуты `write-txn`, `verify-txn`, `run-txn`, `write-journal`, `verify-journal`, `write-journal-txn`, `verify-journal-txn`, `write-journal-txn-nonatomic`. Человек, запустивший стенд без аргументов, видит половину возможностей и не узнает, что есть режим проверки журнала и контрольный неатомарный. Плюс `.dev-team/audit_probes.py` — имя пробы `P1-9 чтение мутирует` печатается и при `HOLDS`, то есть зелёный вердикт читается как «чтение мутирует: ни один путь не пишет». Имя меняется на нейтральное. Продукт не меняется: правка в справке стенда и в подписи пробы.

## Критерий приёмки
Команда возвращает `0`: каждый режим, который код распознаёт (`mode == "<имя>"`), встречается в справке, которую печатает запуск без аргументов, и проба `P1-9` печатает вердикт без слова «мутирует». Заголовок справки не должен утверждать «Три режима», когда их четырнадцать: иначе список полон, а первая строка врёт. Обе стороны: сейчас судья обязан падать, называя восемь неупомянутых режимов; после правки — проходить. Третья сторона: если из справки убрать любой режим обратно, судья обязан снова упасть и назвать именно его — иначе он декоративный.
