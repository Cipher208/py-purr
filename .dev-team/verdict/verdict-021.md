ЗАМЕЧАНИЯ:
1. `## Критерий приёмки` карточки утверждал «полный набор `225 passed`». Факт: `226 passed` на фиксе и доках; `225` — размер набора на `accept-base`. Ни один из шести замороженных ассертов от расхождения не зависит, блокирующим не считаю.
2. README явно говорит «не повторяйте отправку», но не называет возвращаемое значение повторного `send()` — `False`. В CHANGELOG это написано, живой пробой подтверждено.
3. Риск для вызывающего, который игнорирует `committed`, в CHANGELOG и README явно не помечен как принятый/непроверенный; он зафиксирован в ADR (строки 344, 364) и карточке. Не отклоняю: это принятое владельцем ограничение варианта 2.

## Действие лида

Принято. Замечание 1 закрыто до архивации: `225 passed` заменено на измеренное `226 passed`, ни один замороженный ассерт не изменился, строка `ПРАВКА:` с ответом добавлена. Замечания 2 и 3 не блокируют и переносятся в отчёт как явно поименованное непроверенное: README не называет `False` (следующая задача «привести README к факту» это закроет), а принятое ограничение варианта 2 зафиксировано в ADR и карточке.
